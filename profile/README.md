# Verdica

**Team decisions as files in the repo, enforced on every pull request.**

Decisions get made, then quietly violated months later by someone who wasn't in the room. Verdica keeps them where the code is — ratified through PRs, checked on every diff, readable by humans and coding agents alike.

- [verdica](https://github.com/verdicahq/verdica) — the format, the CLI, and the GitHub Action (Apache-2.0)

```bash
pip install verdica && verdica init
```
